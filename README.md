# 四面体魔方 (Pyraminx) 模拟器使用说明

## 概述
这是一个基于代码架构的3D四面体魔方（金字塔魔方）模拟器，支持标准的Pyraminx操作。四面体魔方有4个顶点，每个顶点可以带动相邻的块旋转。

## 基础控制

### 基本旋转操作
四面体魔方有4个轴，每个轴对应一个顶点：

- **U** - 上方顶点旋转（带动相邻的三块）
- **F** - 前下顶点旋转  
- **L** - 左前顶点旋转
- **R** - 右前顶点旋转

### 修饰键控制

#### 旋转方向
- **Shift (左或右)** - 按住时旋转方向反转（逆时针）
  - 默认：顺时针旋转（120°）
  - 按住Shift：逆时针旋转（120°）

#### 旋转深度
- **Ctrl (左或右)** - 按住时进行"浅层"旋转（只带动直接相邻的块）
  - 默认："深层"旋转（带动相邻的三块）
  - 按住Ctrl："浅层"旋转（只带动直接相邻的块）

## 操作示例

### 顶点深层旋转
- 按下 `U` - 上方顶点顺时针深层旋转120°
- 按下 `Shift + U` - 上方顶点逆时针深层旋转120°

### 顶点浅层旋转
- 按下 `Ctrl + U` - 上方顶点顺时针浅层旋转120°
- 按下 `Ctrl + Shift + U` - 上方顶点逆时针浅层旋转120°

## 四面体魔方结构说明

### 块类型
1. **顶点块** - 4个，每个顶点块有3个颜色（小四面体）
2. **棱块** - 6个，每个棱块有2个颜色（中等四面体）
3. **中心块** - 4个，每个中心块连接3个颜色（八面体）

### 颜色表示（标准配色）
从代码可以看出：
- **黄色** - 底面
- **绿色** - 后面
- **红色** - 右面
- **蓝色** - 左面

## 技术实现特点

1. **数据结构**：
   - 使用二进制位表示块的位置（1<<i 表示第i个顶点）
   - 组合位置表示棱块（(1<<i)+(1<<j)）

2. **旋转系统**：
   - 所有旋转基于120°角度进行
   - 使用父子关系实现块组旋转
   - 旋转后更新内部位置表示

3. **动画系统**：
   - 平滑的球面线性插值（Slerp）旋转
   - 旋转速度根据队列长度变化：
     - 队列≤2：慢速（0.2秒）
     - 队列3-5：中速（0.15秒）
     - 队列≥6：快速（0.1秒）

## 视觉结构说明

### 顶点位置
从代码中的pivot数组可以看出四面体的顶点位置：
1. 上方顶点：(0, 1, 0)
2. 前下顶点：(0, -√6/12, -√3/3) 标准化后
3. 左前顶点：(-0.5, -√6/12, √3/6) 标准化后
4. 右前顶点：(0.5, -√6/12, √3/6) 标准化后

### 块的位置
- 中心块（八面体）：位于每个面中心（顶点向量的中间位置）
- 顶点块（小四面体）：位于每个顶点（top = √6/2）
- 棱块（中等四面体）：位于两个顶点的中间位置

## 旋转队列系统

1. **队列机制**：所有旋转操作被加入队列，依次执行
2. **防冲突**：当前旋转完成前不会开始下一个旋转
3. **性能优化**：队列长度影响旋转速度，确保快速操作时有更快的动画

## 注意事项

1. **旋转角度**：四面体魔方旋转角度固定为120°
2. **坐标系**：使用Unity的标准右手坐标系
3. **父子关系**：旋转时临时建立父子关系，旋转后解除
4. **状态保持**：旋转后更新每个块的内部位置表示

4. **性能**：适合在支持硬件加速的设备上运行
